# Make Data Count — Finding Data References — Top Gold Solutions & Post-Mortem

> **Competition**: [Make Data Count - Finding Data References](https://www.kaggle.com/competitions/make-data-count-finding-data-references) (Jun 11 – Sep 9, 2025 | 1,282 Teams | 36,850 Submissions | \$100,000 Prize Pool)  
> **Task**: Extract research dataset persistent identifiers (**DOIs** and repository **Accession IDs**) from full-text scientific articles (`PDF` + `XML`) and classify each citation as **`Primary`** (generated by study) or **`Secondary`** (reused)  
> **Evaluation Metric**: Micro **F1-score** over unique `(article_id, dataset_id, type)` tuples (updated mid-competition so sparsely labeled `Missing` articles are only penalized if explicit labeled negatives are predicted)  
> **Dataset**: `981` train files (`2.13 GB`, ~75% have XML alongside PDF, `325` non-missing train DOI labels) | Hidden Test: `~2,600` Europe PMC OA articles (`~30%` Public / `~70%` Private; `<= 9h` GPU/CPU notebook)

## 1. Universal Long-Document Scientific Extraction Breakthroughs

1. **Upstream Label Provenance & PDF-vs-XML Annotator Parity (`#1`, `#2`, `#3`, `#10`)**:
   - Auditing how ground truth was created saved months of futile NER modeling: DOIs originated from **DataCite / MDC DCC**, Accession IDs from **Europe PMC TextMinedTerms**, and human annotators labeled `Primary`/`Secondary` by reading **PDFs**.
   - **Annotator View Parity (`#2`, `#3`)**: Human annotators did NOT see XML-only online tables — excluding citations appearing exclusively inside XML online-only tables immediately removed pure FPs (`+0.003` Pub / **`+0.004` Priv**, `#2`).
   - **Multiline PDF Wrapping**: DOIs frequently split across PDF line breaks; fast `PyMuPDF` text extraction + whitespace-tolerant regexes (`r'10\s.\s\d{4,9}\s/\s\S+'`, `#8`) + Dryad `.v1/.v2/.v3` version stripping (`#2`) solved recall without slow OCR (`Marker`).
2. **Tuple-F1 Error Asymmetry & Structured Metadata Tabular ML vs. LLMs (`#1`, `#3`)**:
   - Under micro-F1 on `(article_id, dataset_id, type)`, a retrieval error costs **1** error (FP or FN), whereas a **type misclassification on a TP costs 2 errors** (1 FP + 1 FN, `#3`).
   - When rich structured metadata exists (Crossref article title/authors/year + DataCite dataset title/authors/publisher/citation-count), a **6-fold article-grouped CatBoost** decisively beat `Qwen2.5-Coder-32B` on DOI classification (`0.87` type F1, `29 min` total pipeline runtime, `#1`).
3. **Stabilizing Small/Noisy Document Classifiers & Structured Context Windows (`#1`, `#2`, `#3`, `#4`, `#5`)**:
   - Instead of feeding full 15-page papers to LLMs, top solutions extracted targeted structured context: **abstract/intro + mention window (`150–300` chars) + Data Availability + table captions/headers/footnotes (`#4`, `#5`, `#8`)** or **top-3 BM25 chunks (`#2`)**.
   - On noisy small labels (`<1k` train files), standard LLM/encoder fine-tuning diverged across folds. Winners stabilized training via **explicit target-entity masking** (`Prediction {ID}` vs `other dataset id`, `#2`, `#4`), **large batch size (`256`, `#2`)**, **weight EMA (`0.9995`) + gradient clipping (`#3`, `#4`)**, and **article-family majority voting** (`#1`).
   - For inference scaling: **constrained `A`/`B` `MultipleChoiceLogitsProcessor` (`#1`)** without CoT and **3-tier confidence cascading (`14B → uncertain 32B → top-10% 72B`, `#4`)** delivered peak accuracy well inside the 9h budget.

## 2. Master Anti-Patterns & Empirical Negative Results

| Tested Hypothesis | Verified Impact | Teams Reporting | Root Cause |
| :--- | :--- | :---: | :--- |
| **Hard-Coding Public-LB Repository Priors (`BioSample`/`SAMN` = Primary)** | Gained `+0.056` Pub but **lost `-0.016` to `-0.019` Priv** (`#7`, `#9`); `#15` dropped `#4 → #15` | #1, #7, #9, #15 | 30% Public vs 70% Private split had different repository mixes; ML/soft-voting generalized far better |
| **End-to-End LLM Chunk Sweeping / From-Scratch NER** | Severely lagged curated `DCC + EUPMC` candidate sourcing | #2, #5, #9 | Unlabeled valid datasets and upstream NER quirks cause massive FPs under micro-F1 |
| **Using LLMs Where Structured Metadata Tabular ML Fits (DOIs)** | `Qwen2.5-Coder-32B` lost to metadata CatBoost (`#1`) | #1 | Fuzzy author/title/year/count relations are cleanly modeled by GBDTs without token noise |
| **Heavy OCR Parsers (`Marker`) & Chain-of-Thought Classification Prompts** | Blew 9h budget (`#1`, `#9`); CoT added latency with zero/negative F1 gain (`#9`) | #1, #9 | `PyMuPDF` + XML fallback is fast & sufficient; direct constrained `A`/`B` logprobs beat CoT |
| **Naive Small-Batch LLM Fine-Tuning & Unverified Upstream Regexes** | Severe fold instability (`#2`, `#3`); `13/34` MDC validation regexes had unescaped `\d` (`#10`) | #2, #3, #10 | Always audit upstream regexes and stabilize noisy small-N fine-tuning with `bs=256`/EMA/masking |
